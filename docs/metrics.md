# Метрики успадкованого модуля

Спосіб вимірювання: вручну за правилом курсу. CC = 1 + кількість точок розгалуження (if, else if, case, for, foreach, while, catch, &&, ||, ??, тернарний оператор); самостійний else не рахується. LOC — рядки без порожніх і без рядків лише з коментарем.

## Метрики «до»

| Метод | LOC | CC | Глибина вкладеності | Параметрів |
|-------|-----|----|---------------------|------------|
| Handle | 80 | 17 | 4 | 11 |
| Preview | 28 | 9 | 2 | 3 |
| DescribeClient | 10 | 3 | 1 | 1 |
| DumpLog | 6 | 2 | 1 | 0 |
| Клас загалом | 130 | — | — | — |

## Розрахунок CC методу Handle

| Точка розгалуження | Кількість |
|--------------------|-----------|
| if (items != null) | 1 |
| if (items.Count > 0) | 1 |
| if (state == "new" \|\| state == "paid") та оператор \|\| | 2 |
| if (clientMail != null && ...) та оператор && | 2 |
| два цикли for | 2 |
| перевірки виду клієнта (if / else if / else if) | 3 |
| перевірки межі знижки if (> 500m) | 3 |
| if (сума < 1000m) | 1 |
| if (sendMail) | 1 |
| **Разом точок розгалуження** | **16** |
| **CC = 1 + 16** | **17** |

## Додатково

- Відповідальності класу (6): перевірка вхідних даних, обчислення суми, знижки, доставка, форматування звіту, журналювання.
- Дубльованих рядків між Handle і Preview: 14.
- Магічних чисел: 7 (0.15m, 0.30m, 0.05m, 500m, 1000m, 60m, 10).
