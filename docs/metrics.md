# Метрики успадкованого модуля

Спосіб вимірювання: вручну за правилом курсу. CC = 1 + кількість точок розгалуження (if, else if, case, for, foreach, while, catch, &&, ||, ??, тернарний оператор); самостійний else не рахується. LOC — рядки без порожніх і без рядків лише з коментарем. Модуль = усі файли `src/Legacy/*.cs`.

## Розрахунок CC методу Handle («до»)

| Точка розгалуження | Кількість |
|--------------------|-----------|
| if (items != null) | 1 |
| if (items.Count > 0) | 1 |
| if (state == "new" \|\| state == "paid") та оператор \|\| | 2 |
| if (clientMail != null && ...) та оператор && | 2 |
| два цикли for | 2 |
| перевірки виду клієнта (if / else if / else if) | 3 |
| перевірки межі знижки if (> 500m) | 3 |
| if (сума < 1000m) | 1 |
| if (sendMail) | 1 |
| **Разом точок розгалуження** | **16** |
| **CC = 1 + 16** | **17** |

Додатково: відповідальностей класу — 6; дубльованих рядків між Handle і Preview — 14; магічних чисел — 7.
