# Класова модель варіанта 1 (ShopOrders)

## Сутності

| Сутність | Роль | Незмінний | Інваріант |
|---|---|---|---|
| OrderLine | позиція документа | так, record | Quantity > 0, UnitPrice >= 0, Sku не порожній |
| Order | документ зі станом | ні, агрегат | Id > 0; позиції додають лише у стані New; Paid лише за наявності позицій |
| Customer | довідник учасників | так, record | Id > 0, Name не порожнє, Email містить @ |
| Product | довідник обліку | ні (Stock змінюється) | Stock >= 0, Price > 0 |

## Стани документа

| Зі стану | До стану | Умова |
|---|---|---|
| New | Paid | є хоча б одна позиція |
| New | Cancelled | завжди |
| Paid | Shipped | завжди |
| Shipped | Returned | не пізніше 14 днів після відправлення |
